## 🧩 1. The Problem

After every workshop or seminar, someone on the team has to:

1. 🎨 Open the certificate design
2. ⌨️ Type each participant's name into it
3. 💾 Export a file for each person
4. 📧 Email every file to the right person

For 100 attendees that is **hours of repetitive work**, and typos and missed people are common.

## 💡 2. The Solution

CertFlow turns that chore into a few minutes. The organiser opens the **Workspace** and follows five steps:

| # | Step | 🧑 Organiser does | ⚙️ CertFlow does |
|---|------|-------------------|------------------|
| 1 | 🖼️ **Template** | Uploads the certificate design (PDF, PNG, JPG) | Shows a preview |
| 2 | 📊 **Participants** | Uploads the attendee list (Excel or CSV) | Reads it, shows rows and columns found |
| 3 | ✅ **Validate** | Checks the column mapping | Guesses the columns, flags bad emails, missing names and duplicates, and counts valid / invalid / duplicate / excluded |
| 4 | 👀 **Preview** | Picks anyone, moves the name, sets font size and colour | Shows exactly how that certificate will look |
| 5 | 🚀 **Generate** | Ticks "I have reviewed everything" and clicks **Generate Certificates** | Creates one PDF per person with a live progress bar, then offers **Download All as ZIP** |

> 🔍 Nothing is ever dropped silently. Problem rows stay visible, highlighted, with a note saying what is wrong and how to fix it.
